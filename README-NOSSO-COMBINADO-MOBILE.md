Nosso Combinado Mobile 3.7.5

Este é um aplicativo Android híbrido novo que apresenta a versão LIVE do site com acesso rápido ao Comparador de preços, Financeiro e Planejamento mensal. Não é recompilação do APK nativo 2.1.12, pois o código-fonte do app original não está disponível no repositório.
O pacote com.nossocombinado.mobile permite instalação ao lado do APK antigo. Alarmes nativos em segundo plano, notificações push e demais recursos nativos originais não foram migrados.
Compilação via GitHub Actions e disponibilização do APK no GitHub Releases. Não publique senhas, tokens ou chaves privadas no repositório.
